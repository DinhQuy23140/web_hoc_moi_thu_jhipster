# Mầm — học tiếng Anh & tiếng Nhật

Space này được deploy tự động từ GitHub (workflow `deploy-hf.yml`). Đừng sửa file trực tiếp ở đây — mọi thay đổi sẽ bị ghi đè ở lần deploy tiếp theo.

Cấu hình (DB, JWT, admin...) đặt trong **Settings → Variables and secrets** của Space.
